# STAGE DOOR | Summer Stock 2027

Non-Equity-first summer theatre audition dashboard.

## Publish free on GitHub Pages

Go to **Settings > Pages > Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then Save.

Your website address will be: https://areeshdhamani9-netizen.github.io/stage-door-2027/

## Daily source monitoring

GitHub Actions workflow `.github/workflows/check-sources.yml` checks five official casting pages daily at 13:15 UTC. It writes `data/source-status.json` to show check status and detect source page changes. This is not a live audition scraper or verified application feed. Listings require manual review before dates, pay or eligibility change. GitHub may delay or disable scheduled workflows on inactive repositories.

## Privacy

Saved opportunities are stored locally in each visitor's browser. This project is not integrated with ChatGPT's daily audition reminders. No public Higgsfield community listing is involved.
